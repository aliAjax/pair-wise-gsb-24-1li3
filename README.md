# hxwl-10 考古整理入库台

送检批接收登记、待核、修复复验与入库版本管理。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **接收登记**：登记送检批号、探方、地层、件数、保存状况、接收人；提交后与移交单底账比对，批号或坐标对不上自动留待核区
- **待核区**：列出对不上的原因，可复核通过（移交单补正后）或退回移交方
- **修复单**：缺件/残损记录转修复单，写明缺失部位和处理人；复验通过前不能进正式库位
- **入库台**：复验通过后确认件数与库位入库；更正不覆盖旧值，另建带原因的新版本，历史版本可查
- 台帐保存在 localStorage，可一键重置为初始数据

## 代码结构

- `src/data/acceptance.ts` — 验收资料（移交单底账、可选项、初始台帐）
- `src/domain/judgment.ts` — 判定（比对、状态推导、入库门槛、版本追加，纯函数）
- `src/store/localRecords.ts` — 本地记录（localStorage 读写）
- `src/App.tsx` — 页面
