# hxwl-10 出土器物整理入库台

陶片、骨器等送检批的接收登记、移交单核对、缺件修复与入库定版管理。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 业务流程

1. **接收登记**：登记送检批号、探方、地层、坐标、件数、保存状况、接收人；登记即与移交单底账核对。
2. **待核区**：批号或坐标（含探方、地层、件数）与移交单对不上的批次自动留待核区，核对移交单后人工放行。
3. **修复单**：缺件批次转修复单，写明缺失部位和处理人；复验通过前不能进正式库位。
4. **正式库位**：确认入库后件数与库位定版；更正另建原因版本，旧版本保留可查。

## 代码结构（四层分离）

- `src/data/intakeData.ts` — 验收资料：移交单底账、类型定义、示例数据
- `src/domain/intakeRules.ts` — 判定：核对、流转、入库闸口、版本更正的纯函数
- `src/store/intakeStore.ts` — 本地记录：localStorage 持久化
- `src/App.tsx` — 页面：展示与交互
